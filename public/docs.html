Vercel (Gratis, Responsive HP & Laptop)
  1. Push ZIP ke GitHub
  2. Vercel → Import → Deploy
  3. Settings → Domains → Add api.yourdomain.com
  4. DNS CNAME api → cname.vercel-dns.com
